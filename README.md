# Брюсселятор на квадрате: устойчивость и бифуркации

Интерактивные иллюстрации к статье М. Г. Юмагулова, Н. А. Васениной, Р. И. Габдрахманова
«Операторные методы исследования задач об устойчивости и бифуркациях в системе „реакция–диффузия“
и их приложения». Пример — система (30) на квадрате [0, π]² с условиями Неймана.

Страница: https://agufranov.github.io/brusselator-bifurcations/

```
npm install
npm run dev           # http://localhost:5173
npm run build         # статическая сборка в dist/
npm run build:pages   # сборка для GitHub Pages (base = /brusselator-bifurcations/)
```

Разделы страницы:

1. Спектр линеаризации: дисперсионная кривая, нейтральные кривые μ_T(ρ), μ_H(ρ),
   собственные значения B_ρ на комплексной плоскости, карта мод (k, l) с Z₁/Z₂.
2. Карта диффузионной неустойчивости на плоскости (d₁, d₂) и кривая (32).
3. Бифуркационная диаграмма Тьюринга: ветвь, найденная методом Ньютона, и асимптотика теоремы 6.
4. Прямая симуляция PDE (ADI + расщепление Стрэнга) с ростом амплитуды моды cos x cos y.
5. Андронов–Хопф: фазовая плоскость однородной моды и амплитуда цикла от μ.

Код: `src/model.ts` (матрицы B_kl, Z-множества, μ₂), `src/galerkin.ts` (ветвь Тьюринга),
`src/rdsim.ts` (симулятор), `src/hopf.ts` (ОДУ), `src/sections/*` (графики).
Необязательный `src/notes.local.ts` (не хранится в репозитории) добавляет локальные заметки;
публичная сборка (`--mode pages`) его не использует.

Публикация: при пуше в `main` GitHub Actions собирает `build:pages` и выкладывает `dist/` на Pages.
